구글 무료 계정을 활용해 평생 무료로 두 기기를 실시간 연동하는 방법

방법 1. 지금 당장 10초 만에 연동하기 (가장 쉬움) 10초 완성

컴퓨터 우측 상단 [⋮] ➔ [전체 백업(JSON)]을 카톡 '나와의 채팅'으로 폰에 보낸 뒤, 폰에서 [⋮] ➔ [백업 복원]을 누르면 즉시 똑같이 맞춰집니다.

방법 2. 구글 무료 클라우드 키 발급 가이드 (5분 소요) 구글 콘솔 바로가기

1단계: 프로젝트 생성

위 [구글 콘솔 바로가기]를 눌러 구글 로그인 후 [프로젝트 추가] 클릭 ➔ 프로젝트 이름(예: class-3-5) 입력 ➔ 애널리틱스는 끄고 [프로젝트 만들기]를 완료합니다.

2단계: 웹 앱(`</>`) 등록 및 키 복사

프로젝트 홈 화면 중앙의 웹 아이콘 </> 클릭 ➔ 앱 닉네임 입력 후 [앱 등록] ➔ 화면에 나오는 const firebaseConfig = { ... } 코드 전체를 그대로 복사합니다.

3단계: Firestore 데이터베이스 켜기

좌측 메뉴 [빌드] ➔ [Firestore Database] 클릭 ➔ [데이터베이스 만들기] ➔ 위치는 Seoul(asia-northeast3) 선택 ➔ 보안 규칙에서 반드시 '테스트 모드에서 시작'을 선택 후 [사용 설정]을 누릅니다.

4단계: 익명 로그인 허용

좌측 메뉴 [빌드] ➔ [Authentication] 클릭 ➔ [시작하기] ➔ 로그인 제공업체 목록 중 [익명]을 찾아 '사용 설정'을 켜고 저장합니다.
